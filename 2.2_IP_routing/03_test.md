## 3.3 Interpretation
Explain what the ping results mean and what errors might look like.
when the ping is successful, it means the two devices can communicate with each other over the network.We receive
four replies from the Ip address 192.168.50.2, which means the connection is working.

when the ping fails, we get the message "Destination Host Unreachable". This means the device cannot reach the destination IP address,
so there is a problem with the network connection or configuration.
