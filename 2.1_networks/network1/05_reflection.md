## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
_Write answer…_If two PCs have the same IP address, an IP address conflict occurs, causing network communication problems and errors when performing a ping

### 5.2 Why do we use a switch instead of directly connecting PCs together?
_Write answer…_We use a switch because it allows us to connect multiple computers to the same network and communicate more efficiently

### 5.3 What does the subnet mask 255.255.255.0 indicate?
_Write answer…_
The subnet mask indicates which part of the IP address identifies the network and which part identifies the host /device.
